# Лабораторная 7 — теория для защиты

Асинхронный JavaScript, Fetch API, промисы (Promises), формат JSON,
REST API, CORS и динамическая отрисовка данных с сервера.

## Что сделано в работе

1. Реализована функция `loadDishes()`, загружающая список доступных
   блюд с API Московского Политеха:
   `https://edu.std-900.ist.mospolytech.ru/labs/api/dishes`.
2. После получения ответа в формате JSON данные нормализуются
   и передаются в модуль отрисовки (`display.js`).
3. Блюда сортируются по алфавиту по имени (`compareByName`).
4. Все прежние функции (фильтрация, выбор, расчёт стоимости,
   валидация комбо) продолжают работать штатно.
5. Предусмотрен fallback на локальный список блюд на случай
   недоступности университетского сервера.

## Как работает Fetch API (`loadDishes`)

- `fetch(url)` отправляет асинхронный HTTP-запрос методом `GET` и
  возвращает `Promise`, который разрешается объектом `Response`.
- Свойство `response.ok` (HTTP-статус в диапазоне 200–299) проверяет
  успешность запроса. Если статус другой (например, 404 или 502),
  выбрасывается исключение через `throw new Error(...)`.
- Метод `response.json()` читает тело ответа до конца и парсит его
  из строки формата JSON в массив объектов JavaScript. Этот метод
  также возвращает `Promise`.
- В цепочке `.then()` полученный массив сохраняется в переменную
  `dishes`, после чего вызывается отрисовка всех категорий меню.
- Блок `.catch()` перехватывает сетевые сбои (обрыв связи, CORS,
  ошибки парсинга) и обеспечивает отказоустойчивость.

## Асинхронность и Event Loop

- JavaScript является однопоточным языком. Длительные операции
  (сетевые запросы) выполняются асинхронно через Web APIs браузера,
  чтобы не блокировать главный поток отрисовки страницы.
- Обратные вызовы промисов помещаются в очередь микрозадач
  (Microtask Queue) и выполняются сразу после завершения текущего
  синхронного стека вызовов, до рендеринга и макрозадач.

## Что такое CORS

- **Same-Origin Policy (SOP)** — политика безопасности браузера,
  запрещающая чтение ответов на запросы к другому источнику
  (другой протокол, хост или порт).
- **CORS (Cross-Origin Resource Sharing)** — механизм, позволяющий
  серверу разрешить браузеру доступ к своим ресурсам с другого домена
  с помощью HTTP-заголовка `Access-Control-Allow-Origin: *`.
- Без корректных заголовков CORS запрос из GitHub Pages или Netlify
  к внешнему API блокируется браузером на клиенте.

## Вопросы и ответы для защиты

1. **Что возвращает вызов `fetch()`?**
   Объект `Promise`, который переходит в состояние fulfilled при
   получении HTTP-заголовков ответа сервера.
2. **Зачем нужен `response.json()`?**
   Поток данных ответа читается асинхронно и преобразуется из
   JSON-строки в структуры данных JS (объекты/массивы).
3. **Почему `loadDishes` асинхронная?**
   Сетевой запрос занимает неизвестное время. Синхронное ожидание
   заморозило бы интерфейс и вкладку браузера.
4. **Что такое REST API?**
   Архитектурный стиль взаимодействия систем по HTTP с использованием
   стандартных методов (`GET`, `POST`, `PUT`, `DELETE`) и форматов
   данных (чаще всего JSON).
5. **В чём разница между Promise и callback?**
   Промисы избавляют от Callback Hell, позволяют строить удобные
   цепочки `.then().catch()` и имеют четкие состояния:
   pending, fulfilled, rejected.
